La palabra set en inglés tiene varios significados según el contexto. Puede significar poner, colocar, establecer, fijar, configurar, conjunto y otros.

La pronunciación es /set/, parecida a «set» en español, pero pronunciando la e inglesa.

## 1. Los significados principales de set


1\. Poner o colocar

Set = colocar algo en un lugar determinado.

- Set the glass on the table.

  Coloca el vaso sobre la mesa.
- I set my phone on the desk.

  Puse mi teléfono sobre el escritorio.


2\. Establecer o configurar

Set = definir un valor, una opción o una condición.

- Set the default value.

  Establece el valor predeterminado.
- You need to set the database connection.

  Necesitas configurar la conexión a la base de datos.
- I set the timeout to 30 seconds.

  Configuré el tiempo de espera en 30 segundos.


3\. Fijar o programar

Set = determinar una hora, fecha o límite.

- Set an alarm for 6 a.m.

  Programa una alarma para las 6 de la mañana.
- We set a deadline for Friday.

  Fijamos una fecha límite para el viernes.

4\. Conjunto o juego (sustantivo)

A set = un grupo de elementos relacionados.

- A set of tools.

  Un juego de herramientas.
- I bought a set of books.

  Compré un conjunto de libros.


5\. Ponerse (el sol)

Set también se usa para hablar del sol cuando desaparece en el horizonte.

- The sun sets at six.

  El sol se pone a las seis.
- The sun is setting.

  El sol se está poniendo.

## 2. Set en programación

Como desarrollador, encontrarás esta palabra frecuentemente en código, documentación y entrevistas técnicas.

| Inglés           | Significado                     | Ejemplo                   |
| ---------------- | ------------------------------- | ------------------------- |
| Set a value      | Establecer un valor             | `setValue(10)`            |
| Set a property   | Asignar una propiedad           | `setProperty()`           |
| Set up a project | Configurar un proyecto          | Set up the project.       |
| Set a variable   | Asignar un valor a una variable | Set the variable to true. |
| A set of data    | Un conjunto de datos            | A set of records.         |

Por ejemplo:

English: First, we need to set the user's role.

Español: Primero, necesitamos establecer el rol del usuario.

English: You can set the state using the setter function.

Español: Puedes establecer el estado usando la función que lo actualiza.

En React, por ejemplo:

```js
const [count, setCount] = useState(0);

setCount(5);
```

Aquí `setCount` es el nombre de una función que actualiza el estado `count`.

## 3. Diferencia entre set, put y place

Las tres palabras pueden significar «poner», pero tienen matices diferentes.

| Palabra | Uso habitual                                                     | Ejemplo                                                                    |
| ------- | ---------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Put     | Poner algo en algún lugar; uso general                           | Put the book here. — Pon el libro aquí.                                    |
| Set     | Colocar o dejar algo en una posición; también establecer valores | Set the alarm. — Programa la alarma.                                       |
| Place   | Colocar algo de manera más deliberada o formal                   | Place the document on the desk. — Coloca el documento sobre el escritorio. |

## 4. Las formas del verbo set

Una característica importante es que set no cambia de forma en pasado ni como participio.

| Tiempo     | Forma   | Ejemplo                    |
| ---------- | ------- | -------------------------- |
| Presente   | Set     | I set the value.           |
| Pasado     | Set     | I set the value yesterday. |
| Participio | Set     | I have set the value.      |
| Gerundio   | Setting | I am setting the value.    |

Observa:

- I set the password yesterday. — Establecí la contraseña ayer.
- I have set the password. — He establecido la contraseña.
- I am setting the password. — Estoy estableciendo la contraseña.

La palabra setting también puede significar «configuración» en contextos tecnológicos: Change the settings = Cambia la configuración.

## 5. Practica tu inglés

1\. What does 'Set the default value' mean?

Eliminar el valor predeterminado

Establecer el valor predeterminado

Consultar el valor predeterminado

¡Correcto! Set significa establecer o asignar en este contexto.

2\. Which sentence is in the past?

I am setting the value.

I have set the value.

I set the value yesterday.

¡Correcto! Set conserva su forma en pasado. 'Yesterday' indica que la acción ocurrió ayer.

3\. What does 'a set of tools' mean?

Una herramienta configurada

Un conjunto de herramientas

Configurar las herramientas

¡Correcto! Aquí set es un sustantivo que significa conjunto o juego.

Reiniciar ejercicio

Consejo: cuando encuentres set en una frase, no lo traduzcas automáticamente como «poner». Primero identifica si habla de colocar un objeto, establecer un valor, programar algo o referirse a un conjunto. El contexto te dará la traducción correcta.
