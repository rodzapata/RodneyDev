¡Excelente! Ya tenemos el modelo de EF Core construido y la conexión con PostgreSQL funcionando.

Ahora pasaremos de la configuración a una prueba importante: guardar y recuperar una orden de trabajo con sus actividades y preguntas.

Antes de escribir código, hay una decisión de diseño que debemos tener clara:

- `WorkOrder` es el agregado raíz.
- `WorkOrderActivity` pertenece a ese agregado.
- `WorkOrderActivityQuestion` y `ActivityAnswer` son elementos internos de cada ejecución.

Por tanto, cuando recuperemos una orden para trabajar con sus actividades, debemos cargar también las colecciones necesarias. No queremos consultar cada elemento de forma independiente sin necesidad.

### Paso 1. Crear una consulta para recuperar la orden completa

Actualmente tu repositorio tiene este método:

```csharp
Task<WorkOrder?> GetByIdAsync(
    Guid id,
    CancellationToken cancellationToken);
```

Mi recomendación es conservarlo y agregar otro método llamado `GetByIdWithDetailsAsync`. Así puedes recuperar una orden sencilla cuando no necesitas todos sus detalles y cargar el agregado completo cuando vas a consultar o modificar sus actividades.

1\. Actualiza `IWorkOrderRepository.cs`:

```csharp

using AcSoft.Domain.Entities;

namespace AcSoft.Application.Abstractions.Persistence;

public interface IWorkOrderRepository
{
    Task AddAsync(
        WorkOrder workOrder,
        CancellationToken cancellationToken);

    Task<WorkOrder?> GetByIdAsync(
        Guid id,
        CancellationToken cancellationToken);

    Task<WorkOrder?> GetByIdWithDetailsAsync(
        Guid id,
        CancellationToken cancellationToken);
}

```

2\. Actualiza `WorkOrderRepository.cs`:

Agrega este método a tu implementación:

```csharp

public async Task<WorkOrder?> GetByIdWithDetailsAsync(
    Guid id,
    CancellationToken cancellationToken)
{
    return await _context.WorkOrders
        .Include(x => x.Activities)
            .ThenInclude(x => x.Questions)
        .Include(x => x.Activities)
            .ThenInclude(x => x.Answers)
        .FirstOrDefaultAsync(
            x => x.Id == id,
            cancellationToken);
}

```

Asegúrate de tener estos espacios de nombres:

```csharp
using Microsoft.EntityFrameworkCore;
```

### ¿Qué estamos cargando?

WorkOrder

- Activities

  Ejecuciones de actividades de la orden.
- Questions

  Preguntas guardadas como snapshot.
- Answers

  Respuestas de cada ejecución, incluyendo sus objetos de valor y mediciones configurados como entidades propiedad de EF Core.

Una consideración importante: no estamos cargando las actividades originales del catálogo porque esta consulta está orientada a recuperar la información histórica de la orden.
