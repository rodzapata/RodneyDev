¡Perfecto! Continuemos con la creación de nuestra primera migración de ACSoft: `InitialCreate`.

Esta migración generará la estructura de tablas de PostgreSQL a partir de las entidades y configuraciones que hemos construido con DDD y EF Core 10.

## **Paso 1. Verificar que tienes instalada la herramienta EF Core**

Desde PowerShell, en la raíz de `AcSoft-BackEnd`, ejecuta:

```bash
dotnet ef --version
```

Deberías obtener una versión `10.0.4`.

Si aparece que no se reconoce el comando, instala la herramienta:

```bash
dotnet tool install --global dotnet-ef --version 10.0.4
```

Si ya la tienes instalada, pero con otra versión:

```bash
dotnet tool update --global dotnet-ef --version 10.0.15
```

## **Paso 2. Crear la migración**

Ejecuta desde la raíz de la solución:

```bash
dotnet ef migrations add InitialCreate `
    --project .\AcSoft.Infrastructure `
    --startup-project .\AcSoft.Api `
    --output-dir Persistence\Migrations `
    --context AcDbContext
```

Al ejecutar este comando me salia un error de Microsoft.CodeAnalysis.Workspaces, Version=5.0.0.0

lo que hice fue borrar de la caché local con el comando

```bash
dotnet restore --force
```

y despues compilar de nuevo

```bash
dotnet build
```


**¿Qué significa cada parámetro?**

| Parámetro           | Función                                                           |
| ------------------- | ----------------------------------------------------------------- |
| `InitialCreate`     | Nombre de la migración                                            |
| `--project`         | Proyecto donde se guardarán las migraciones                       |
| `--startup-project` | Proyecto que proporciona la configuración de ejecución y conexión |
| `--output-dir`      | Carpeta donde se guardarán                                        |
| `--context`         | Contexto de EF Core que utilizaremos                              |

- Que `WorkOrders` tenga sus columnas y restricciones.
