## 1. Actualizar MaintenancePlanActivityConfiguration

Agregaremos la relación con `Activity` mediante `ActivityId`.

En `MaintenancePlanActivityConfiguration.cs`, agrega:

```csharp
builder.HasOne<Activity>()
    .WithMany()
    .HasForeignKey(x => x.ActivityId)
    .OnDelete(DeleteBehavior.Restrict);
```

La configuración completa de las relaciones quedaría así:

```csharp
builder.HasOne<MaintenancePlan>()
    .WithMany(x => x.Activities)
    .HasForeignKey(x => x.MaintenancePlanId)
    .OnDelete(DeleteBehavior.Cascade);

builder.HasOne<Activity>()
    .WithMany()
    .HasForeignKey(x => x.ActivityId)
    .OnDelete(DeleteBehavior.Restrict);
```

¿Por qué `Restrict` en la actividad?

Porque una actividad del catálogo podría estar siendo utilizada por varios planes. No queremos que eliminar una actividad provoque la eliminación de información relacionada con esos planes.

## 2. Configuración de Activity

Crea:

`AcSoft.Infrastructure/Persistence/Configurations/ActivityConfiguration.cs`

```csharp
using AcSoft.Domain.Entities;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata.Builders;

namespace AcSoft.Infrastructure.Persistence.Configurations;

public sealed class ActivityConfiguration
    : IEntityTypeConfiguration<Activity>
{
    public void Configure(EntityTypeBuilder<Activity> builder)
    {
        builder.ToTable("Activities");

        builder.HasKey(x => x.Id);

        builder.Property(x => x.Code)
            .HasMaxLength(30)
            .IsRequired();

        builder.HasIndex(x => x.Code)
            .IsUnique();

        builder.Property(x => x.Name)
            .HasMaxLength(150)
            .IsRequired();

        builder.Property(x => x.Description)
            .HasMaxLength(500)
            .IsRequired();

        builder.HasMany(x => x.Questions)
            .WithOne()
            .HasForeignKey(x => x.ActivityId)
            .OnDelete(DeleteBehavior.Cascade);

        builder.Navigation(x => x.Questions)
            .HasField("_questions")
            .UsePropertyAccessMode(PropertyAccessMode.Field);
    }
}
```

Esta configuración presupone que `ActivityQuestion` tiene una propiedad `ActivityId`, como sugiere la llamada `ActivityQuestion.Create(Id, ...)`.

## 3. Actualizar AcDbContext

Actualmente tienes:

```csharp
public DbSet<WorkOrder> WorkOrders { get; set; }
```

Más adelante agregaremos los demás `DbSet`, pero no quiero asumir todavía todas tus entidades.

Por ahora, las configuraciones se pueden registrar mediante:

```csharp
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    base.OnModelCreating(modelBuilder);

    modelBuilder.ApplyConfigurationsFromAssembly(
        typeof(AcDbContext).Assembly);
}
```

Esto permite que EF Core descubra automáticamente las clases que implementan `IEntityTypeConfiguration<T>` dentro del ensamblado de Infrastructure.
